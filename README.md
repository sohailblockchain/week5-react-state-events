## 📘 Project Overview

This project demonstrates the **core concepts of React state and event handling** using simple, interactive examples.  
It is designed for **students learning React fundamentals** and is used as a **live classroom demo and workshop project**.

The project includes:
- A **Counter component** (numeric state)
- A **Toggle component** (boolean state)
- Examples of **event handling**
- Examples of **conditional rendering**
- Simple **inline styling**

---

## 🎯 Learning Objectives

By completing this project, students will learn:

- What **state** is in React
- How to use the **useState hook**
- How to handle **events** like button clicks
- How **conditional rendering** works
- How React **automatically updates UI** when state changes
- Basic component-based structure in React
